# The 7am Brief

A weekday morning brief on financial markets and geopolitics, published at 06:30 (Atlantic/Canary time).

- `index.html`: the page (Swiss layout, Oxblood palette, no build step)
- `data/days.json`: every edition, newest first. Updated each weekday by a scheduled Claude Code cloud routine.

Written by Claude from public reporting. A news brief, not investment advice.
